# OnlyFoods Backend

Backend API of the mobile app OnlyFoods

Read Documentations folder for calling the API

## Setting up developer environment and packages

```
pip install uv      # if uv is not installed
uv sync             # Copies the packages
```

## Runnning the dev server

Create a `.env` file, copy the API names from `.env.example`. Paste the API keys in the `.env` file.

Then run:

```
uv run main.py
```
